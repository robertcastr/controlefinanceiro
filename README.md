# NEXO — Controle Financeiro

Aplicativo de gestão financeira pessoal offline em C# WinForms (.NET 8).

Inclui dashboard, histórico inteligente, contas, transferências, categorias, orçamentos, recorrências, gráficos, relatórios, backup e planejamento de pagamentos com valores diferentes a cada mês.

## Executar

No Windows com SDK .NET 8, rode `dotnet run`.

Dados em `%LocalAppData%\ControleFinanceiro\dados.json` (não subir ao GitHub). Faça backup antes de atualizar.

Ainda não validado em uma compilação Windows neste ambiente.
